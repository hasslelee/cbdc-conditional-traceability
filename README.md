# 조건부 추적 CBDC 연구

거래 내용을 암호화하고, 여러 기관이 동의할 때만 열람키를 복구하도록 구성한 연구 프로토타입의 개요입니다.

## 이 저장소의 범위

이 저장소에는 연구 개요만 있으며 실행 코드와 검증 로그는 들어 있지 않습니다.

## 수행한 연구 (2025.06–2025.12)

- Hyperledger Besu 위에서 거래 내용을 AES-GCM으로 암호화해 기록했습니다.
- 감사 열람키를 Shamir 비밀분산으로 5개 기관에 나누었습니다(3개 이상 동의 시 복구).
- 지분 2개로는 복구에 실패하고 3개로는 성공하는 것을 확인했습니다.
- 열람 주체·대상·시각·사유를 감사 원장에 기록하도록 구현했습니다.

Shamir 비밀분산을 사용했고 분산 키 생성(DKG)을 구현한 것은 아닙니다. BBS+ VC 선택적 공개는 설계 범위입니다. 테스트 네트워크의 연구 프로토타입이며 실제 금융망에서 운영한 것이 아닙니다. 관련 연구를 CISC-W 2025에서 제1저자로 포스터 발표했습니다.
